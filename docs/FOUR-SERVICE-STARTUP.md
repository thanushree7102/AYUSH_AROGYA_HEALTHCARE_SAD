# Unani service startup

Run `npm install`, copy `.env.example` to `.env`, then run `npm run dev`. The command starts the event bus, shared platform, common clinical service, Unani service, longitudinal record service, integrations service, API gateway and the Unani Vite frontend. Open `http://localhost:5173`.

Use `npm start` for backend services only, `npm run dev:frontend` for the frontend only, `npm run build` to build the frontend, `npm run check` for JavaScript syntax checks, and `npm test` for the deployment smoke test.
